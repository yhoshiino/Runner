# Robot Run

**Robot Run** is an endless runner game developed with **SFML 3.0.2**. Play as a robot in a waste factory and try to collect as many lightning bolts as possible while avoiding obstacles. The conveyor belt gradually speeds up, making the challenge increasingly intense!

## 🎮 Gameplay

- **Objective:** Collect as many lightning bolts as possible while avoiding obstacles.
- **Environment:** A waste factory with an endless conveyor belt.
- **Difficulty:** The conveyor belt gradually increases speed, making the game progressively harder.
- **Controls:**
  - `W` : Move up  
  - `S` : Move down  
  - `A` : Move left  
  - `D` : Move right  

## 🏃 Features

- **Endless gameplay:** The game never ends; keep going until you hit an obstacle.  
- **Progressive speed increase:** The longer you survive, the faster the conveyor belt becomes.  
- **Score system:** Collect lightning bolts and survive as long as possible to increase your score.  
- Developed using **C++20** and **SFML 3.0.2**.
